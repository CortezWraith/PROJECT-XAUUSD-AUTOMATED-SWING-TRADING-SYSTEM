# 20. Zdroje

Seznam zdrojů použitých v rešerši (kapitola 5), pro data (kapitola 3) a pro broker realitu
(kapitola 17). U akademických prací je uveden rok publikace a periodikum. Plné texty části

(viz kapitola 19). Hodnocení věrohodnosti: recenzované časopisecké práce [E] mají nejvyšší váhu,
preprinty a institucionální texty střední, praktické články a diskuse jen podpůrnou.
